Configure config.json Settings

Configuration file controls the behaviour of the computer on which it is installed. Computers in different areas (e.g. main floor, lab, classroom) can have different have config files to provide different setting or different “three extra buttons”. See instructions for the location for the config.json file or PCs or Macs.

Customize Your MorphicBar
