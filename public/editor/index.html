Configure config.json Settings

Configuration file controls the behaviour of the computer on which it is installed. Computers in different areas (e.g. main floor, lab, classroom) can have different have config files to provide different setting or different “three extra buttons”. See instructions for the location for the config.json file or PCs or Macs.

Default Settings

These settings are not usually changed but are included here for completeness.

Customize Your MorphicBar

Enterprises can customize the MorphicBar with up to three additional buttons via the config file. You can use the same set of custom buttons across all your computers or you can create location- specific sets of 3 buttons (e.g., classrooms, library, labs) by simply using different config files in those computers.

You can use any combination of pre-defined or custom URL buttons that you like but you can only add a total of 3 buttons.

  1. to add a button just click the checkmark next to the button (or button type)
  2. then select which position on the bar you would like the button
  3. if you want more than one “Application Button” or “Custom URL button” use the “+ Add Another ______ Button”
